## A. 桌面调试版 BOM（电源适配器供电，先跑通再说）

> **何时选这套**：你**第一次**做鸭子，所有舵机和主控都还没有在整机里塞过。先用外置 URT-2 + 7.5V/3A 适配器跑通"URT-2 → 总线 → 舵机"全链路，再考虑整机集成。  
> **优点**：① 不装电池 → 短路风险低；② 主控外置 → 烧镜像 / 接屏 / SSH 调试都方便；③ 舵机可以单独测试 → 出问题直接换；④ 15 颗舵机一起抓总线 → 比塞进鸭子再 debug 容易 10 倍。  
> **可与整机集成版共用物料**：HD-1910、Radxa Zero 3W、IMU、轴承、3D 打印件、M2 螺丝——这些**两套都要买**。

### B.2 替代件清单（如果 A 套用 URT-2 不打算转 HAT 板）

有些朋友桌面调试期用 URT-2，**直接**进整机——这意味着 URT-2 也塞进鸭子内部，可行但**线束较乱**。如果要保持整洁，建议：

- B2' **改用 DC-DC + 飞特官方 HAT 板**（JoyandAI 设计，GitHub 已开源）
- B7' 电池仓+主板仓 一体化 3D 打印件

> ⚠️ **电池警告**：
> - 2S 锂电短路会**喷火**，务必加保险丝；
> - 第一次上电**全程有人看着**；
> - 不使用时电池单独存放，**不要塞在鸭子里过夜**。

> 💡 **电池容量选型**：
> - 7.4 V / 3400 mAh：站立 + 慢走约 30 min，激烈动作约 15 min
> - 7.4 V / 5200 mAh：站立 + 慢走约 50 min，激烈动作约 25 min（淘宝 50–60 元）

## E. 易买错清单（请务必核对）

| ❌ 错买 | ✅ 正确 | 原因 |
|---|---|---|
| HL-2915-C002 | **HD-1910-C001** | HL-2915 是 9–14 V，2S 电池带不动；脚序还相反 |
| XL330-M288-T | **HD-1910-C001** | XL330 是原版舵机，国内难买 + 超压运行 |
| NP-F970 电池 | **2S 18650 锂电池组** | F970 太大塞不进鸭子；2S 18650 才是复刻圈主流 |
| M3 螺丝 | **M2 自攻螺丝** | 原版关节孔位是 M2 系统（`fanhao375` 已从 STL 孔特征反推） |
| 凹舵盘的 8 个连杆件 | **`-FT` 后缀的 8 个连杆件** | HD-1910 是**凸舵盘**，8 个连杆件必须换，否则装不上 |
| 飞特 HLS 协议寄存器 | **STS 协议寄存器** | HD-1910 是 STS 系列，不是 HLS |
| DC 5.5×2.5 插头适配器 | **DC 5.5×2.1 插头** | URT-2 是 2.1 口径；2.5 插不进去 |
| 飞特 SC-05 协议舵机 | **SC-15 或 HD-1910** | SC-05 电压电流规格不够，**不要买** |
