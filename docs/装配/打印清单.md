# 3D 打印清单

> **核心原则**：**不要从本仓库拿 STL**，请去官方仓库拉原版 STL 二次开发。
> 打印参数来自 `JoyandAI/OpenMicroDuck` 仓库的 `docs/cad.md` + `fanhao375/microduck-replica` 仓库的 `docs/硬件入门.md` 双源校验。

---

## 一、STL 来源

### 主源：Pollen Robotics 官方

```bash
# 官方真机端
git clone https://github.com/pollen-robotics/microduck.git
ls microduck/microduck_description/   # 47 个原始 STL
```

### 二次开发源：fanhao375 CAD 仓库（推荐）

```bash
git clone https://github.com/fanhao375/microduck-replica-cad.git
```

`fanhao375/microduck-replica-cad` 提供了：
- 可编辑的 **SolidWorks** 工程（不是仿真直出的 STL）；
- **STEP** 中性文件（任何 CAD 软件都能打开）；
- 适配 **HD-1910 凸舵盘**的 `-FT` 后缀件（**8 个与舵盘配合的连杆件必须用这版**）；
- 完整的**装配 BOM**（含立创商城编号）。

> ⚠️ **凸舵盘警告**：HD-1910 的舵盘与原版 XL330 凸凹相反。直接拿原版 STL 打印会**装不上**。**8 个连杆件必须换成 `-FT` 后缀的版本**。

### 教程源：AI-FanGe 预构建镜像（参考）

```bash
git clone https://github.com/AI-FanGe/Microduck-build-tutorial.git
```

> ⚠️ AI-FanGe 仓库的 STL 是**原版 XL330 版本**，不能直接用——需要把 8 个连杆件换成 HD-1910 凸舵盘版。

## 二、打印件清单（按承力 / 装配位置分类）

### 2.1 承力件（务必用 PETG）

| 部位 | 数量 | 备注 |
|---|---|---|
| 髋关节外壳 | 2 | 左 / 右各一 |
| 大腿连杆 | 2 | 左 / 右 |
| 小腿连杆 | 2 | 左 / 右 |
| 踝关节外壳 | 2 | 左 / 右 |
| 肩部连杆 | 2 | 左 / 右 |
| 头颈支撑 | 1 | — |
| 罩壳（下巴 / 后脑） | 2 | — |

**打印参数**：
- **材料**：PETG
- **层高**：0.20 mm
- **壁数**：5 壁
- **顶底**：5 层
- **填充**：40% gyroid（抗剪切 + 易支撑拆除）
- **喷嘴**：0.4 mm
- **打印方向**：按最大受力面朝上

### 2.2 非承力件（PLA 即可）

| 部位 | 数量 | 备注 |
|---|---|---|
| 嘴部外壳 | 1 | — |
| 眼睛装饰件 | 2 | — |
| 电池盒 | 1 | 整机集成用 |
| 主板固定板 | 1 | 装 Radxa Zero 3W |
| HAT 固定板 | 1 | 装 HAT 板（如果用） |
| 舵机走线槽 | 若干 | — |

**打印参数**：
- **材料**：PLA
- **层高**：0.20 mm
- **壁数**：3 壁
- **填充**：20%
- **喷嘴**：0.4 mm

### 2.3 柔性件（必须 TPU）

| 部位 | 数量 | 备注 |
|---|---|---|
| **脚垫** | 2 | 显著提升站立稳定性 |
| 嘴部缓冲垫 | 1 | 可选 |

**打印参数**：
- **材料**：TPU 95A（**不要买 85A，太软**）
- **层高**：0.20 mm
- **壁数**：3 壁
- **填充**：30%
- **喷嘴**：0.4 mm（**0.6 mm 更好**，TPU 易堵嘴）
- **打印速度**：30 mm/s（**比 PLA 慢一半**）
- **退料设置**：开启（避免拉丝）

## 三、打印后处理

### 3.1 去支撑

- PETG 支撑用**树状支撑**（易拆、不留疤）；
- TPU **不要打支撑**（拆不下来），用**专用切片**避免悬空；
- PLA 用默认支撑即可。

### 3.2 孔位修正

- M2 自攻孔位，**逐个用 M2 螺丝试攻**（如果太紧，用 1.9 mm 钻头预扩）；
- 轴承孔位（6700K、ET2216）用对应外径的**铰刀**精修（公差 0.05 mm）。

### 3.3 表面处理（可选）

- 外观件（罩壳、嘴部）用 **120 → 240 → 400 目**砂纸打磨；
- 喷漆前用 **0.1 mm 腻子**补打印层纹；
- 黄色主体 + 橙色嘴部 + 黑色眼睛的经典配色用**丙烯颜料**即可。

## 五、打印时间估算

| 类别 | 件数 | 预计总打印时间 |
|---|---|---|
| 承力件 PETG | ~14 件 | ~20 h |
| 非承力件 PLA | ~20 件 | ~15 h |
| 柔性件 TPU | 3 件 | ~3 h |
| **合计** | ~37 件 | **~38 h** |

> 💡 多台打印机并行（如家里有 2 台 Bambu A1 mini）可缩短到 ~20 h。

## 六、外包打印参考

如果自己没有 3D 打印机，可以去淘宝搜"3D 打印服务"，按 200–300 元/套（含 PETG + PLA + TPU）报预算。

打印服务店铺推荐询问的参数：
- 打印精度（建议 0.16 mm 或更细）；
- 支撑是否包含（要包）；
- 后处理（打磨 / 喷漆）是否包含；
- 邮费（建议顺丰到付）。
