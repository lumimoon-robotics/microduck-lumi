# 整机集成上电流程

> **核心原则**：5 步逐级上电，**绝对不要跳级**。每步不通过**回退上一级**。  
> 流程来自 `fanhao375/microduck-replica` 的 `调试记录.md` + `sim336/OptiDuck` 的 v1.04 实机总结 + `JoyandAI/OpenMicroDuck` 的"分阶段 BOM"思路 三源校验。

---

## 〇、推荐路线：先桌面调试 → 后整机集成

> ⚠️ **本教程的核心方法论**——**先跑通电源适配器 + 外置 URT-2 的桌面版本，再切电池做整机集成**。不要反过来。  
> 这个顺序直接来自 `JoyandAI/OpenMicroDuck` README 的 "桌面调试 vs 整机集成" 分阶段方案，结合 `fanhao375/microduck-replica` 的踩坑记录，**强烈推荐**。

### 为什么要分两阶段？

| 阶段 | 关键差异 | 适合做什么 | 不适合做什么 |
|---|---|---|---|
| **桌面调试（A 套）** | URT-2 板 + 7.5V/3A 适配器外置；主控外置可接屏 | 配 ID、单舵机测试、悬吊跑策略、烧镜像、SSH 调试 | 整机组装、电池短路测试、真实行走 |
| **整机集成（B 套）** | 2S 锂电池 + DC-DC 降压 + 动力开关塞进鸭子 | 整机行走、续航测试、稳定性跑测 | 反复拆舵机测、烧镜像、接 HDMI 调试 |

**简单说：能外置就外置，**所有"舵机能不能响、主控能不能跑通总线"的验证，**都先在桌面上完成**。等桌面版本完全跑通 30 分钟不翻车，再把同样的舵机/主控塞进鸭子切电池。

### 阶段切换清单（从 A 切到 B 之前逐项确认）

- [ ] 15 颗舵机都在 URT-2 总线上能 scan 到（`servo-web` / `feetech_scan` 工具）
- [ ] 单舵机扫频测试全过（延迟、堵转、堵转电流都在规格书范围内）
- [ ] 离线 ONNX 推理在 URT-2 + 15 舵机上跑通，悬吊 30 分钟不报总线错误
- [ ] 零位 / 方向 / 限位三组标定都已写入 `config/calibration.json`
- [ ] 飞特 URT-2 板的"协议切换拨码"位置记录好了（方便上 HAT 板时回滚）
- [ ] 准备好**保险丝 + 动力开关**（电池**必装保险丝**！）
- [ ] 桌面留出 1m² 软垫 + 软护栏空间

> ✅ 全部勾完才能进入"二、5 步逐级上电"的 **步骤 1**；  
> 任意一项没勾 → 回 `BOM-含淘宝链接.md` 的 A 套清单继续采购。

### 两阶段的物料差异

| 物料 | A 套（桌面） | B 套（整机） |
|---|---|---|
| 7.5V/3A 桌面适配器 | ✅ 必备 | ❌ 不需要 |
| 2S 锂电池 | ❌ 闲置 | ✅ 必备 |
| DC-DC 降压 | ❌ 闲置 | ✅ 必备 |
| 动力开关 + 保险丝 | ❌ 闲置 | ✅ 必备 |
| 飞特 URT-2 板 | ✅ 必备 | ⚠️ 可选（HAT 板替代）|
| 5V/3A PD 适配器 | ✅ 必备 | ❌ 不需要（DC-DC 替代）|
| 15 颗 HD-1910 | ✅ 必备 | ✅ 共用 |
| Radxa Zero 3W | ✅ 必备 | ✅ 共用 |
| IMU LSM6DSV16X | ✅ 必备 | ✅ 共用 |

详细差异见 `docs/采购/BOM-含淘宝链接.md`。

## 一、装配总流程

> **装配顺序在两阶段中通用**——下面每个步骤都标注了 **[桌面]** 或 **[整机]** 表示该步骤在哪一阶段执行。

```
源装配 → 左腿五轴链 → 躯干背包 → 右腿（镜像）→ 头颈/嘴部 → 罩壳
```

每步装完**通电测单舵机**（URT-2 + 上位机 `servo-web` 网页调试台），确认零位和正方向再装下一步。

### 1.1 源装配 [桌面]

- **准备**：5 颗舵机（用于左腿），1 颗 URT-2，1 块 7.5V/3A 桌面电源；
- **步骤**：
  1. 把 5 颗舵机的 ID 改为 21–25（详见 `舵机配ID与方向校正.md`）；
  2. 用 `servo-web` 把 5 颗舵机都转到中位（2048），断电；
  3. 装到左腿连杆上（**注意方向**，舵盘凸面朝外）；
  4. 通电，确认 5 颗都能正常响应指令。
- **验收**：5 颗舵机都能控制，转向与指令一致，无异响。

### 1.2 左腿五轴链 [桌面 → 整机]

- **步骤**：
  1. 把左腿整体与躯干连接件对接（**先用 1 颗 M2 螺丝定位**）；
  2. 接好 5 颗舵机的菊花链（**线序飞特脚序 1=Signal 2=Vcc 3=GND**）；
  3. 通电，让 5 颗舵机各做 ±30° 摆动，看是否互相干涉；
  4. 拧紧所有 M2 螺丝。
- **验收**：左腿能独立完成"抬腿 / 蹬腿 / 摆腿"三个动作，无卡顿、无异响。

### 1.3 躯干背包 [桌面 → 整机]

- **步骤**：
  1. 装 Radxa Zero 3W 到主板固定板（**Type-C 接口朝外**方便调试）；
  2. **[桌面]** 阶段 ② 跳过电池相关步骤，**主控外置**就行；
  3. **[整机]** 阶段 ② 装 DC-DC 降压模块（7.4V → 5V/3A 给主控 Type-C 供电）；
  4. 装 IMU LSM6DSV16X 模块到头颈俯仰轴附近（用 I²C 接口）；
  5. 走线（**舵机大电流走主干，不要绕过 IMU 小板**）。
- **验收**：主控上电，UART2 能正常读到 5 颗舵机的 ID（21–25）。

### 1.4 右腿（镜像）[桌面]

- **步骤**：同 1.1、1.2，**ID 改 11–15**（与左腿镜像）；
- **特别注意**：
  - 镜像后**关节正方向相反**，需要在 `calibration.json` 里把 `direction` 设为 -1；
  - 左右腿的舵盘凸面都朝外（**朝身体中线**）。
- **验收**：左右腿能独立抬起，整机悬吊状态下不会"劈叉"。

### 1.5 头颈 / 嘴部 [桌面]

- **步骤**：
  1. 装 4 颗头颈舵机（ID 31–34），1 颗嘴部舵机（ID 1）；
  2. 头颈 4 颗 + 嘴 1 颗装好后通电测单舵机；
  3. 把头颈与躯干连接；
  4. 走线（头颈部走线要留余量，否则抬头低头会扯线）。
- **验收**：头颈能独立完成"点头 / 摇头 / 歪头"，嘴能开合。

### 1.6 罩壳 [整机]

> 桌面调试阶段**最后才装**罩壳——因为头颈/嘴部动作还要反复调试。

- **步骤**：把下巴、后脑、眼睛装饰件装上；
- **检查**：所有线束不能压在罩壳下，否则会磨破短路。

## 二、5 步逐级上电

> **阶段对应**：步骤 1–2 走 **A 套（桌面调试）**；步骤 3 起逐步进 **B 套（整机集成）**。所有阶段都用 URT-2 + 7.5V 适配器接入；进入 B 套后保留 URT-2 协议桥（也可切 HAT 板）。

### 步骤 1：单舵机夹具辨识（1–2 天）[桌面]

- **目标**：拿到 15 颗舵机的实测参数（延迟 / 死区 / 回差 / 负载响应）；
- **方法**：
  1. 用 URT-2 + **7.5V/3A 桌面电源**；
  2. 用 `servo-web` 的"扫频模式"测单舵机响应；
  3. 用 `servo-web` 的"回差测试"测齿轮间隙；
  4. 把结果填入 `config/calibration.json`；
- **不通过 → 排查**：单颗舵机有问题直接换（同批次的可以挑出来一起退）。

### 步骤 2：离线回放（半天）[桌面]

- **目标**：在不上机的情况下验证 ONNX 策略输出范围；
- **方法**：
  ```bash
  python scripts/infer_policy.py --policy policies/walk.onnx --mode replay
  ```
  看输出动作是否在舵机行程内（±150° 以内）。
- **不通过 → 排查**：
  - 输出超行程 → ONNX 训练时未做动作裁剪 → 重新训练
  - 输出抖动大 → 观测归一化没做 → 检查 ONNX 输入是否已经归一化

### 步骤 3：悬吊（1–2 天）[桌面 → 整机过渡]

- **目标**：让策略在真机上跑起来，看舵机是否按预期动；
- **方法**：
  1. 用一根绳子**从天花板 / 龙门架**把鸭子吊起来（**不能用手提**，会歪）；
  2. 起动 `robotd`（50 Hz 控制环）；
  3. ARM（力矩使能）；
  4. 观察舵机动作（应该是按策略缓慢摆动，不会乱甩）；
  5. 测 30 分钟，看温升（外壳不烫手为合格）。
- **不通过 → 排查**：
  - 舵机乱甩 → `calibration.json` 零位错 → 重新校准
  - 舵机不响应 → 飞特脚序接反 → 断电检查
  - 单腿抖 → 单颗舵机回差太大 → 换舵机

### 步骤 4：单腿（1 天）[整机]

- **目标**：单独测试一条腿的步态策略；
- **方法**：
  1. 拆掉另一条腿（4 颗 M2 螺丝）；
  2. 鸭子侧躺在软垫上；
  3. 启动步态策略；
  4. 观察单腿是否能完成"抬 / 蹬 / 摆"循环。
- **不通过 → 排查**：
  - 抬腿高度不够 → 调高 hip_pitch 目标角度（手动改 ONNX 后处理）
  - 蹬腿力度不够 → 查 hip_pitch / knee 协同
  - 摆腿方向反 → 查髋关节 direction 是否对

### 步骤 5：受保护站立（2–3 天）[整机]

- **目标**：让鸭子**站在桌面上**（软垫）不倒；
- **方法**：
  1. 桌面铺**厚软垫**（瑜伽垫 5 cm 厚）；
  2. 鸭子脚底贴**防滑贴**（TPU 脚垫 + 砂面）；
  3. 周围一圈**软护栏**（纸箱 / 靠垫 / 毛巾卷）；
  4. 人在旁边**随时准备接住**；
  5. ARM，触发站立策略；
  6. 观察 1 分钟看是否站住。
- **不通过 → 排查**：
  - 站起后倒 → 重心偏 → 调 hip_yaw / hip_roll 零位
  - 站起后震颤 → 控制环频率不稳 → 检查 50 Hz 中断延迟
  - 站起后慢慢倒 → IMU 没接 / 没校准 → 检查 I²C 是否通

### 步骤 6：系绳慢走（3–5 天）[整机]

- **目标**：让鸭子**在桌面上慢走**（有保护）；
- **方法**：
  1. 头颈套一根**弹性绳**（能接住，但不阻碍正常动作）；
  2. 软护栏同步骤 5；
  3. 启动步态策略；
  4. **第一周只走 1 步 / 慢走**，看是否会倒；
  5. 通过后再走 3 步 / 5 步 / 10 步。
- **不通过 → 排查**：
  - 走 1 步就倒 → 单腿 / 站立还没稳，回退
  - 走到第 N 步倒 → 步态策略累积误差 → 调 ONNX
  - 走的方向偏 → 髋关节零位偏 → 重做 calibration

## 三、上电时序

> **关键警告**：`fanhao375/microduck-replica` 踩坑记录里专门提到 **URT-2 的上电顺序**——必须**先开 URT-2 电源 → 再接 USB 到主控**，否则会触发总线错误。

### 3.1 第一阶段：桌面调试上电（电源适配器 + URT-2）[A 套]

> **何时用**：你刚把 15 颗舵机买回来，第一次通电测试。  
> **没有电池、没有短路风险**，可以放心接。

```
1. 插上 7.5V/3A 适配器 → URT-2（绿灯亮）
2. 等待 2 秒 → 总线稳定
3. 插上 USB-A → 主控 Radxa Zero 3W（或直接接 PC）
4. 主控登录 → 检查 /dev/ttyS2 是否能 scan 到 15 颗舵机
5. 启动 robotd → ARM
```

### 3.2 第二阶段：整机集成上电（2S 电池 + HAT 板）[B 套]

> **何时用**：桌面调试**完全跑通**之后，切电池进鸭子。  
> **电池上电前**务必确认 〇 节"阶段切换清单"全部勾完。

```
1. 装好 2S 锂电池（XH2.54 已接好）
2. 关闭动力开关（保险丝那端）
3. 闭合动力开关 → 舵机总线通电
4. 等 2 秒 → 装好 DC-DC 降压到主控的线
5. 主控 Type-C 供电 → 启动
6. 主控登录 → 检查总线
7. 启动 robotd → ARM
```

> ⚠️ **拆电池顺序与上电相反**：
>
> 1. 主控 shutdown
> 2. 拔 Type-C
> 3. 断开动力开关
> 4. 拔 XH2.54  
>    **不要带电拔电池**！

## 四、验收标准

| 项目       | 目标                                                |
| -------- | ------------------------------------------------- |
| 50 Hz 控制 | 并发 30 min，P99 ≤ 15 ms，10 s 窗平均 49–51 Hz，失约 ≤ 0.1% |
| 故障       | 拔 USB / 进程退出 / 坏包重复包 / MCU 复位 → 进入既定状态，重连不自行运动    |
| 站立       | 5 min × 3 次，无保护架承重或异常重启                           |
| 行走       | 前进 1 m / 左右转 / 停步各 10 次，每类 ≥ 9 次成功                |
| 温升       | 30 min 悬吊测试，外壳温度 < 45°C（手感温热不烫）                   |
