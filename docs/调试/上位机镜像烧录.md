# 上位机镜像烧录（Radxa Zero 3W）

> **来源**：Radxa 官方文档 + `fanhao375/microduck-replica` 仓库的 `tools/radxa/` + `sim336/OptiDuck` 仓库的 `board/` 三源校验。

---

## 一、选择系统

Radxa Zero 3W 支持多个系统：

| 系统 | 推荐度 | 适用场景 |
|---|---|---|
| **Radxa OS**（Debian 12 bookworm） | ⭐⭐⭐⭐⭐ | **本教程默认**（官方支持，5 min 烧好） |
| Armbian 25.x（社区版） | ⭐⭐⭐⭐ | 习惯 Armbian 的玩家（`fanhao375` 用的就是这个） |
| Ubuntu 22.04 | ⭐⭐⭐ | 老手用，新手不推荐 |
| Android | ⭐ | 本教程不适用（不能跑 ONNX Runtime） |

> `sim336/OptiDuck` 实测内核：`6.1.84-10-rk2410-nocsf`（Radxa OS 25.x 自带）。

## 二、烧录准备

### 2.1 物料

- Radxa Zero 3W 主板
- 64 GB MicroSD / TF 卡（A2 等级）
- 读卡器（USB 2.0 够用）
- 电脑（macOS / Linux / Windows 都可以）
- 5 V / 3 A Type-C PD 电源适配器
- USB Type-C 数据线（**必须是数据线，不是只充电的**）
- MicroHDMI ↔ HDMI 线（可选，看接不接显示器）

### 2.2 下载镜像

- **Radxa OS**：https://github.com/radxa-build/radxa-zero3-image-releases/releases
- **Armbian**：https://www.armbian.com/radxa-zero-3/

> 💡 **下载建议**：选 `desktop` 版本（带 GUI），方便新手。生产环境用 `minimal` 即可。

## 三、烧录步骤（以 Radxa OS 为例）

### 3.1 macOS / Linux

```bash
# 1. 插入 SD 卡
# 2. 查看 SD 卡设备号
diskutil list            # macOS
lsblk                    # Linux

# 3. 卸载 SD 卡
diskutil unmountDisk /dev/disk2     # macOS
sudo umount /dev/sdb1               # Linux

# 4. 烧录（用 balenaEtcher 或 dd）
# 推荐 balenaEtcher 图形化：https://etcher.balena.io/
# 或命令行：
sudo dd if=radxa-zero3_radxa-os_bookworm_xxx.img of=/dev/rdisk2 bs=4m status=progress     # macOS
sudo dd if=radxa-zero3_radxa-os_bookworm_xxx.img of=/dev/sdb bs=4M status=progress         # Linux
```

### 3.2 Windows

- 下载 **Raspberry Pi Imager**（https://www.raspberrypi.com/software/）；
- 选择镜像 → 选择 SD 卡 → 写入；
- 比 balenaEtcher 简单。

### 3.3 第一次启动

```
1. SD 卡插入 Radxa Zero 3W
2. 接上 MicroHDMI（可选）
3. 接上 5V/3A Type-C 电源
4. 蓝色 LED 亮 = 上电成功
5. 等待 30-60 秒
6. 通过 HDMI 接键盘鼠标 / 通过 USB 串口登录
```

### 3.4 第一次配置

- **默认用户**：`radxa` / `radxa`（或 `root` / `radxa`，看版本）
- **第一次登录**会要求改密；
- **如果是 Armbian**：`root` / `1234`（`fanhao375` 仓库已确认），按提示改密。

## 四、系统配置

### 4.1 网络配置

#### 4.1.1 有线（推荐先用）

- Radxa Zero 3W 有千兆网口，插网线即用；
- 默认 DHCP 自动获取 IP；
- `ip addr` 查看 IP。

#### 4.1.2 无线（后续用）

```bash
# 查看 wlan0 是否起来
ip link show wlan0

# 如果没起来，加载驱动（如果用 Armbian）
sudo modprobe brcmfmac

# 扫描 WiFi
sudo nmcli device wifi list

# 连接
sudo nmcli device wifi connect "你的SSID" password "你的密码"

# 验证
ping 8.8.8.8
```

> ⚠️ **wlan0 DHCP 抽风**（`fanhao375` 已知坑）：Radxa Zero 3W 默认 Armbian 镜像的 wlan0 DHCP 偶发抽风，建议**先插网线**，WiFi 留到整机阶段再开。

### 4.2 安装基础包

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git vim python3-pip python3-venv \
                    build-essential cmake libssl-dev \
                    i2c-tools can-utils minicom \
                    libatlas-base-dev libopenblas-dev
```

### 4.3 安装舵机相关

```bash
# Python 飞特协议库（社区版）
pip3 install feetech-servo

# 验证
python3 -c "import feetech; print('feetech installed')"

# 如果想用 rustypot（推荐）
git clone https://github.com/pollen-robotics/rustypot.git
cd rustypot
cargo build --release
```

### 4.4 安装 ONNX Runtime

```bash
# 通用 CPU 版本（Radxa Zero 3W 的 0.8 TOPS NPU 本教程不用，CPU 够）
pip3 install onnxruntime
# 验证
python3 -c "import onnxruntime; print(onnxruntime.__version__)"
# 推荐 1.28.0+（sim336/OptiDuck v1.03 实测）
```

### 4.5 串口配置（接舵机）

```bash
# 查看串口
ls -l /dev/ttyS*

# 应该是：
# /dev/ttyS0  = 调试串口
# /dev/ttyS2  = 飞特舵机总线（UART2）
# /dev/ttyS3  = 蓝牙
# /dev/ttyS4  = WiFi

# 启用 UART2
sudo raspi-config
# → Interface → Serial → Enable (No console)
# 或
sudo systemctl stop serial-getty@ttyS0.service
sudo systemctl disable serial-getty@ttyS0.service

# 设置权限
sudo usermod -aG dialout $USER
```

### 4.6 I²C 配置（接 IMU）

```bash
# 安装 i2c-tools
sudo apt install -y i2c-tools

# 扫描 I²C 设备
sudo i2cdetect -y 3   # I2C-3 (IMU 默认)

# 应该看到 LSM6DSV16X 在 0x6a
```

## 六、首次启动

### 6.1 跑 mock 后端（不接硬件）

```bash
cd ~/microduck-replica-cn
python3 -m src.main --backend mock
```

应该看到：
```
[INFO] Backend: mock
[INFO] Loading ONNX policy: policies/walk.onnx
[INFO] Mock control loop started at 50 Hz
```

### 6.2 接舵机总线（URT-2 模式）

```bash
# URT-2 插到 Radxa Zero 3W 的 USB
# 7.5V 适配器插到 URT-2

python3 -m src.main --backend urt2 --calibrate config/calibration.json
```

应该看到：
```
[INFO] Backend: urt2
[INFO] Scanning /dev/ttyUSB0 ...
[INFO] Found 15 servos: [11, 12, 13, 14, 15, 21, 22, 23, 24, 25, 31, 32, 33, 34, 1]
[INFO] All servos responding. Starting 50 Hz loop.
```

### 6.3 跑真机（URT-2 模式）

```bash
# 同上，但加 --arm 参数
python3 -m src.main --backend urt2 --calibrate config/calibration.json --arm
```

## 七、常见问题

### 7.1 SD 卡启动不了

- 重新烧镜像（SD 卡可能损坏）；
- 检查 SD 卡是否 A2 等级（低速卡会卡住启动）；
- 换 SD 卡（推荐 SanDisk Extreme 64 GB）。

### 7.2 wlan0 找不到

```bash
sudo modprobe brcmfmac
sudo systemctl restart NetworkManager
```

### 7.3 串口没权限

```bash
sudo usermod -aG dialout $USER
# 重新登录
```

### 7.4 I²C 找不到 IMU

```bash
# 1. 检查接线（SDA, SCL, GND, 3.3V）
# 2. 检查地址（LSM6DSV16X 默认 0x6a）
sudo i2cdetect -y 3
# 3. 如果没设备，检查 3.3V 供电（IMU 模块需 3.3V，不能 5V）
```
