## 二、Python 网页调试台（servo-web）

### 2.1 功能

- 浏览器拖滑块控制单舵机（可视化、所见即所得）；

- 紧急停止按钮（一键卸力）。

### 2.4 关键代码

```python
# feetech.py 关键片段（来自 fanhao375/microduck-replica 仓库）
import serial
import struct

class FeetechServo:
    def __init__(self, port, baudrate=1000000, timeout=0.1):
        self.ser = serial.Serial(port, baudrate, timeout=timeout)

    def ping(self, id):
        """PING 指令"""
        pkt = bytes([0xFF, 0xFF, id, 0x02, 0x01])
        pkt += bytes([(~sum(pkt[2:])) & 0xFF])
        self.ser.write(pkt)
        return self.ser.read(6)[4] == id

    def write_byte(self, id, addr, value):
        """WRITE 写一个字节"""
        pkt = bytes([0xFF, 0xFF, id, 0x04, 0x03, addr, value])
        pkt += bytes([(~sum(pkt[2:])) & 0xFF])
        self.ser.write(pkt)

    def read_word(self, id, addr):
        """READ 读两个字节"""
        pkt = bytes([0xFF, 0xFF, id, 0x04, 0x02, addr, 0x02])
        pkt += bytes([(~sum(pkt[2:])) & 0xFF])
        self.ser.write(pkt)
        data = self.ser.read(8)
        lo, hi = data[5], data[6]
        return (hi << 8) | lo

    def sync_read_position(self, ids, start_addr=56):
        """SYNC_READ 批量读位置"""
        n = len(ids)
        pkt = bytes([0xFF, 0xFF, 0xFE, n*2+4, 0x82, start_addr, 0x02] + ids)
        pkt += bytes([(~sum(pkt[2:])) & 0xFF])
        self.ser.write(pkt)
        positions = []
        for i in range(n):
            data = self.ser.read(5 + i*5)  # 累加读取
            lo, hi = data[5 + 3], data[5 + 4]
            positions.append((hi << 8) | lo)
        return dict(zip(ids, positions))
```

> ⚠️ **SYNC_READ 累加读取**是飞特协议的细节——返回的不是 15 个独立包，**是连续字节流**。`fanhao375` 仓库的 `feetech.py` 处理得很优雅，建议直接看原文。

## 三、协议级模拟器（不接硬件自检）

> `fanhao375` 仓库提供 `mock_feetech.py`，**协议层完全 mock，但接口和真硬件一致**——可以在没接舵机的情况下测试整个控制环。

### 3.1 用法

```python
# 把 import 换成 mock
from mock_feetech import FeetechServo as Servo

# 后续代码与真硬件完全一致
servo = Servo(port='/dev/null', baudrate=1000000)
servo.ping(1)  # 永远返回 True
pos = servo.read_word(1, 56)  # 返回 2048（中位）
```

### 3.2 用途

- 单元测试（CI 跑 24/7 不需要硬件）；
- 算法迭代（先在模拟器上跑通控制环，再上真机）；
- 培训新人（不需要买舵机就能学协议层）。

## 四、Rust 板载实现（rustypot）

### 4.1 为什么 Rust

- **零依赖静态编译**（Radxa Zero 3W 上没 systemd 也能跑）；
- **无 GC 抖动**（50 Hz 实时控制环必备）；
- **生态完善**（`pollen-robotics/rustypot` 已支持飞特 STS/SCS 协议）。

### 4.2 安装

```bash
cargo install rustypot
# 或从源码
git clone https://github.com/pollen-robotics/rustypot
cd rustypot
cargo build --release
```

### 4.3 关键代码

```rust
// 来自 pollen-robotics/rustypot 仓库
use rustypot::{FeetechActuator, FeetechBus};

fn main() {
    let bus = FeetechBus::new("/dev/ttyS2", 1_000_000);

    // 同步读 15 颗舵机位置
    let ids = [11, 12, 13, 14, 15, 21, 22, 23, 24, 25, 31, 32, 33, 34, 1];
    let positions: Vec<i16> = bus.sync_read_present_position(&ids).unwrap();
    println!("Positions: {:?}", positions);

    // 同步写目标位置
    let targets = vec![2048; 15];
    bus.sync_write_goal_position(&ids, &targets).unwrap();
}
```

### 4.4 与 `pollen-robotics/microduck` 集成

- `fanhao375` 仓库已写 `FeetechIo`（跟 `pollen-robotics/microduck` 的 `robotd` 集成）；
- 直接把 `FeetechIo` 替换 `DxlIo` 即可；
- `rustypot` 已升级到 v1，跟上官方 0.14.1。

## 五、URT-2 自带软件（Feetech Debug Center）

### 5.1 平台

- Windows / macOS / Linux 都有；
- 飞特官网下载：https://www.feetechrc.com/down/

### 5.2 主要功能

- 扫总线（看哪些 ID 在）；
- 配 ID；
- 单舵机位置 / 速度 / 扭矩控制；
- 实时波形显示；
- 读温度 / 电压 / 负载；

### 5.3 局限

- 只能**单舵机 / 整总线**控制，**不能分组控制**；

> 💡 **推荐用法**：配 ID + 刷固件 + 配单舵机参数用 URT-2 自带软件；联调 / 算法迭代 / 真机部署用 `servo-web`。

## 七、协议层易错清单

| ❌ 错 | ✅ 对 | 原因 |
|---|---|---|
| 校验和用 (sum & 0xFF) | **用 (~sum & 0xFF)** | 飞特是按位取反，不是按位与 |
| 默认 0xFE 当 ID 用 | **0xFE 是广播地址** | 广播不能读返回 |
| 把 ID 当成无符号 | **ID 范围 0–253** | 254 = 广播，255 = 保留 |
| 同时给 15 颗发 WRITE | **用 SYNC_WRITE 批量写** | 50 Hz × 15 颗 × 5 字节 = 总线压力 |
| 把 READ 当成原子操作 | **用 SYNC_READ** | 单读 15 颗慢 15 倍，破坏 50 Hz |
| 用 5 字节返回格式 | **飞特是 6 字节返回** | 第二个 0xFF 是 header，不是 payload |

## 八、调试技巧

### 8.1 总线扫描不到任何舵机

```bash
# 1. 检查接线（飞特脚序 1=Signal 2=Vcc 3=GND）
# 2. 检查供电（5V 桌面电源是否通电）
# 3. 检查 UART 串口（/dev/ttyS2 是否启用）
# 4. 检查波特率（飞特默认 1 Mbps）
# 5. 用示波器 / 逻辑分析仪看波形
```

### 8.2 总线偶尔掉线

- **线材问题**：换特软硅胶线（带屏蔽），缩短到 < 30 cm；
- **阻抗不匹配**：菊花链末端加 120 Ω 终端电阻（如果总线 > 50 cm）；
- **驱动能力不足**：URT-2 驱动 15 颗舵机可能不够，换成**总线中继器**或**自驱动板**。

### 8.3 单舵机温升异常

```python
# 读 Present Temperature
temp = servo.read_byte(63)
if temp > 60:
    print("舵机过热！立即断电检查")
```

- 60–70°C：减负载 / 加散热片；
- > 70°C：**立即断电**，可能是齿轮卡死或堵转过久。

### 8.4 周期性抖动

- 检查 50 Hz 中断延迟（`htop` 看 CPU 占用）；
- 检查 `robotd` 进程是否被 swap（用 `systemd-run --scope --user` 固定优先级）；
- 隔离 I/O：舵机 I/O 与 IMU I/O 不要共享线程。
