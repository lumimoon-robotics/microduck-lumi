# 安全与故障保护

> **本教程原则**：**软硬件双保险**——软件卸力不能代替动力开关，协议层故障保护不能代替物理保险丝。
> **来源**：`microduck-lumi` 项目自身 + `JoyandAI/OpenMicroDuck` + `fanhao375/microduck-replica` 三源校验。

---

## 一、硬性安全规则（必须实现）

### 1.1 协议层（板端固件 / 50 Hz 控制环）

- **连续 100 ms 无新有效目标帧 → 锁存故障、丢弃积压、尝试关闭力矩**；
- 坏包 / 重复包 / 心跳**不续命**（不因为"还在线"就忽略错误包）；
- 上电、重连**不自动运动**，恢复需人工复位并重新 ARM；
- 软件卸力**不能代替**动力开关；
- 任何时候**堵转测试都要把电压限制在 5 V 以下**（8.4 V 满电 + 堵转 = 舵机壳体烧穿）。

### 1.2 物理层（电源管理）

- **两路电源严禁正极并接**（电池正极与适配器正极接一起会短路烧板）；
- 舵机大电流**不走** URT-2 的 5 A 通路（URT-2 不扛 15 颗堵转）；
- 2S 锂电必须加**保险丝 + 动力开关**（5 A 保险丝足够）；
- 第一次上电**全程有人看着**；
- 长时间调试**必须用桌面电源**（有线路线），不要随便接电池；
- 不使用时电池**单独存放**，不要塞在鸭子里过夜。

### 1.3 操作层

- 桌面调试期装**拉绳 / 急停开关**串在动力线上；
- 第一次悬吊测试**至少两人**（一人操作、一人接）；
- 周围不要有易碎品 / 笔记本 / 宠物；
- 准备好**灭火毯 / 沙包**（2S 锂电短路会喷火）；
- 任何时候**堵转测试都要把电压限制在 5 V 以下**。

## 二、舵机过流保护

### 2.1 单舵机过流

```python
# feetech.py 增加过流保护
def sync_read_with_protection(self, ids, max_current_ma=1500):
    """带过流保护的同步读"""
    positions = self.sync_read_present_position(ids)

    for id in ids:
        load = self.read_word(id, 60)  # Present Load
        if abs(load) > max_current_ma:
            print(f"WARNING: Servo {id} overload! Disabling torque.")
            self.write_byte(id, 40, 0)  # Torque Off

    return positions
```

### 2.2 整机过流

- **电池保险丝**：5 A 自恢复保险丝（PTC）；
- **DC-DC 过流保护**：选 5 V/3 A 限流版（淘宝 5–15 元）；
- **软件监控**：每 100 ms 读一次总线电流，> 4 A 立即 ARM off。

## 三、IMU 失效保护

### 3.1 检测

```python
def read_imu_with_check():
    """IMU 读 + 健康检查"""
    try:
        data = i2c.read(LSM6DSV16X_ADDR, 0x22, 14)  # 0x22-0x2F
        if data is None or len(data) < 14:
            return None
        return parse_imu(data)
    except OSError:
        return None  # I²C 错误
```

### 3.2 失效动作

- **IMU 失效 → 紧急卸力**（**不靠 IMU 不可能稳定**，必须立即停）；
- 在 `robotd` 里加：
  ```rust
  if imu.is_none() {
      bus.write_torque_enable(&ALL_IDS, false);
      return Err("IMU failure, torque disabled");
  }
  ```

## 四、电池过放保护

### 4.1 电压监控

| 阈值 | 电压 | 动作 |
|---|---|---|
| 满电 | 8.4 V | 正常 |
| 正常 | 7.4–8.0 V | 正常 |
| 低电 | 6.8 V | 警告（OLED 显示 / 状态灯） |
| **关断** | **6.6 V** | **卸力**（`sim336/OptiDuck` 默认阈值） |
| 极低 | 6.0 V | **硬关断**（切断动力开关） |

### 4.2 实现

```python
# 每 1 秒读一次电池电压
def battery_monitor(bus):
    while True:
        voltage = read_battery_voltage()  # 通过 ADC 读电池电压
        if voltage < 6.0:
            bus.write_torque_enable(ALL_IDS, False)
            trigger_emergency_shutdown()  # 切断动力开关
        elif voltage < 6.6:
            bus.write_torque_enable(ALL_IDS, False)  # 软关断
        time.sleep(1)
```

> 💡 **为什么 6.6 V 软关断**：`sim336/OptiDuck` v1.02 实测，2S 电池在 6.6 V 以下带不动 15 颗舵机，会持续报"电压不足"。

## 五、通信失效保护

### 5.1 心跳检测

- 主机 → 下位机：每 50 Hz 一帧（20 ms 间隔）；
- 下位机：连续 5 帧（100 ms）未收到 → 锁存故障，卸力。

### 5.2 实现

```c
// ESP32 固件伪代码
void on_uart_frame(uint8_t* buf, int len) {
    last_heartbeat = millis();
    parse_frame(buf, len);
}

void loop() {
    if (millis() - last_heartbeat > 100) {
        // 100ms 没收到心跳
        bus.write_torque_enable(ALL_IDS, false);
        fault_led.on();
    }
}
```

## 六、紧急停止

### 6.1 物理急停（推荐）

- **自锁式急停按钮**（淘宝 5–10 元）串在动力线上；
- 按下立即切断动力（**硬关断**，不依赖软件）；
- 装在鸭子背部，方便触及。

### 6.2 软件急停

- 主机键盘按 `q` 立即卸力：
  ```python
  import keyboard
  while True:
      if keyboard.is_pressed('q'):
          bus.write_torque_enable(ALL_IDS, False)
          print("EMERGENCY STOP")
          break
  ```
- 板端 OLED 显示 "EMERGENCY STOPPED"。

### 6.3 App 急停

- `sim336/OptiDuck` 仓库有 Android App（Kotlin + Jetpack Compose），带急停按钮；
- 通过 BLE 发送急停指令。

## 七、温升保护

### 7.1 阈值

| 部位 | 温度 | 动作 |
|---|---|---|
| **舵机** | 60–70°C | 警告（降低输出扭矩） |
| **舵机** | **> 70°C** | **立即卸力**（齿轮卡死或堵转过久） |
| 主控 | 70–80°C | 警告（加散热片） |
| 电池 | > 50°C | 警告（停止使用，冷却后再用） |
| 电池 | **> 60°C** | **立即断电**（热失控临界） |

### 7.2 监控

```python
def thermal_monitor(bus):
    while True:
        max_temp = 0
        for id in ALL_IDS:
            temp = bus.read_byte(id, 63)  # Present Temperature
            max_temp = max(max_temp, temp)

        if max_temp > 70:
            bus.write_torque_enable(ALL_IDS, False)
            print(f"EMERGENCY: Servo temp {max_temp}°C > 70°C, torque disabled")
            break
        time.sleep(5)
```

## 八、起火应急

### 8.1 2S 锂电起火

- **不要用水**（锂电燃烧会产生氢氟酸，水加剧）；
- **用灭火毯 / 沙包**（淘宝 30 元灭火毯必备）；
- 或用 **D 类灭火器**（氯化钠粉）；
- 切断电源（拔电池 / 关动力开关）；
- 把起火的电池移到**空旷无人区**（不要在桌面烧）。

### 8.2 应急包清单

- [ ] 灭火毯（1 张）
- [ ] 沙包（2 个，可 DIY 装沙子的小布袋）
- [ ] 防火手套（1 双）
- [ ] 护目镜（1 副）
- [ ] D 类灭火器（可选，社区/学校有）
